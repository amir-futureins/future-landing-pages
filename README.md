# Future Insurance — דפי נחיתה לגוגל אדס

| קובץ | מה זה |
|---|---|
| `mortgage-insurance.html` | דף 1 — הוזלת ביטוח משכנתא / חיים |
| `health-insurance.html` | דף 2 — בדיקת כפל ביטוחי בריאות / מחלות קשות |
| `car-insurance-history.html` | דף 3 — בדיקת עבר ביטוחי לרכב / היעדר תביעות |
| `thank-you.html` | דף תודה — כאן נורית ההמרה של Google Ads (פעם אחת לכל ליד) |
| `privacy.html` | תנאי שימוש, מדיניות פרטיות, מדיניות עוגיות והצהרת נגישות — נפתחים גם כחלון קופץ מכל הדפים |
| `assets/js/config.js` | **הקובץ היחיד לעריכה**: טלפון, וואטסאפ, כתובת Apps Script, מזהי Google Ads |
| `assets/js/core.js` | ולידציות, מסכות, טופס רב-שלבי, שליחה, UTM/gclid — משותף לכל הדפים |
| `assets/css/style.css` | מערכת העיצוב המשותפת |
| `google-apps-script.gs` | קליטת לידים ל-Google Sheets (לשונית נפרדת לכל דף: משכנתא / בריאות / רכב, עמודות אוטומטיות) |

## לפני עלייה לאוויר
1. **פרטים משפטיים** — ב-`config.js`: `licenseNumber` (מספר רישיון), `email` (חובה בהצהרת הנגישות), ולוודא את `cookieMode`. הערכים מתעדכנים אוטומטית בכל הדפים.
1א. **בדיקת עורך/ת דין** — לעבור על `privacy.html` (נוסח בסיס) לפני עלייה לאוויר.
2. **המלצות** — הטקסטים והתמונות בסקשן "לקוחות מספרים" הם דוגמה. להחליף בהמלצות אמיתיות באישור הלקוחות.
3. **תמונת סוכן** — מומלץ מאוד להחליף את העיגול `א״ש` בתמונה אמיתית (מעלה אמון).
4. **רשימת החברות** — להשאיר רק חברות שאתם באמת עובדים מולן.
5. **Apps Script** — הסקריפט הקיים שלכם ממשיך לעבוד (נשלחים גם שמות השדות הישנים), אבל ת.ז, מבוטחים נוספים ו-gclid יישמרו רק אם תעדכנו אותו לקוד שב-`google-apps-script.gs` (ואז Deploy → Manage deployments → New version).
6. **Google Ads** — למלא `gtagId` ו-`conversionSendTo` ב-`config.js`. להגדיר בקמפיין את `thank-you.html` כדף ההמרה.
7. **HTTPS חובה** — הדף אוסף ת.ז; לארח רק עם SSL.

## בדיקה מקומית
```
cd landing-pages && python3 -m http.server 8000
```
ואז לפתוח http://localhost:8000/mortgage-insurance.html
